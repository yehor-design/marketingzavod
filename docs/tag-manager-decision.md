# Менеджер тегів: рішення

Рішення від 25 листопада 2026: на `marketingzavod.com` теги GA4, Google Ads, Meta і LinkedIn вантажить **Google Tag Manager у браузері**. Cloudflare Zaraz і серверний GTM не використовуються.

## Варіанти, які розглядалися

| | GTM у браузері | Cloudflare Zaraz | Серверний GTM (Stape, Cloud Run) |
| --- | --- | --- | --- |
| Як працює | Браузер вантажить `gtm.js`, а він — `gtag.js`, `fbevents.js` тощо; дані йдуть напряму в Google і Meta | Браузер шле події на власний піддомен, сервери Cloudflare пересилають їх у GA4 | Браузер шле події на власний піддомен, серверний контейнер розсилає їх далі |
| Що потрібно | Нічого, DNS лишається у Vercel | Перенести DNS домену на Cloudflare | Хостинг контейнера і DNS-запис |
| Вартість | 0 | 0 до 1 млн подій на місяць | Stape Free до 10 тис. запитів, далі від 20 USD на місяць; Cloud Run від ~120 USD на місяць |
| Вага сторінки після згоди | +150–250 КБ скриптів Google і Meta | один невеликий скрипт | невеликий скрипт |
| Втрати через блокувальники | частина подій GA4 і пікселя губиться | майже немає | майже немає |
| Можливості реклами | повні: ремаркетинг Google Ads, Google Signals, браузерний піксель Meta | частина функцій браузерних тегів недоступна | повні, але складніше налаштувати |
| Налагодження | GTM Preview, Tag Assistant | лише debug-режим Zaraz | GTM Preview для обох контейнерів |

## Чому GTM

- Простіше і стандартно: імпорт `gtm/container.json` і публікація, без переносу DNS.
- Повні можливості для реклами, яку планується запускати.
- Втрати заявок через блокувальники компенсує сервер: `/api/lead` надсилає `Lead` і `CompleteRegistration` у Meta Conversions API з тим самим `event_id`, що й піксель.
- До згоди нічого не вантажиться, тож перше завантаження сторінки однакове для всіх варіантів.

## Коли повернутися до питання

- Якщо частка подій, які губляться через блокувальники, стане помітною: порівняй заявки в HubSpot з `generate_lead` у GA4 (див. `reporting-setup.md`, «Чому цифри не збігаються»).
- Якщо вага скриптів після згоди почне заважати бюджету швидкості (`performance-budget.md`).
